# IPTV Player (iOS)
1. Bu klasörün içeriğini GitHub reposuna yükle (.github klasörü dahil).
2. Actions -> "iOS IPA Derle" calisir (macOS, ~5-10 dk). Artifacts -> IPTVPlayer-ipa indir (zip icinden IPTVPlayer.ipa).
3. IPA imzasizdir: Sideloadly veya AltStore ile kendi Apple ID'nle imzalayip iPhone'a kur.
